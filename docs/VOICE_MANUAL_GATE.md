# VOICE MANUAL GATE (PR2) — 30 живых диалогов

Автоматика покрывает протокол (`tests/test_voice_ws.py`).
Ухо и микрофон автоматикой не покрыть: этот gate проходится вручную
в Chrome на `http://127.0.0.1:8080/voice`, результаты фиксируются таблицей.

## Процедура

1. `make up`, открыть `/voice`, разрешить микрофон.
2. Каждый диалог: говорить естественно, минимум 5 диалогов — с перебиванием
   (начать говорить поверх ответа ассистента).
3. Критерий прохождения диалога: задача решена (запись/смещение/статус),
   `booking_id` на dashboard совпадает с `/appointments`, без выдуманных слотов.

## Порог

- 30/30 задач решены, 0 галлюцинированных слотов.
- Barge-in останавливает речь во всех 5+ пробах (субъективно < 500мс).
- p95 задержки хода по dashboard — записать факт, цель ≤ 2.5с.

Локальные движки (GigaAM/Silero) — вне PR2; провайдеры-заглушки лежат
в `voice/stt.py` / `voice/tts.py` (`LocalSTTStub` / `LocalTTSStub`).
