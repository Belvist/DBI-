# Продуктовый бриф (черновик под чекпоинт 15.10)

## Проблема
Колл-центр клиники тратит операторов на типовые обращения: «запишите к терапевту»,
«когда моя запись?», «перенесите», «кто сегодня принимает?».

## Аудитория
Пациент, которому нужно записаться / перенести / уточнить расписание — голосом,
без ожидания оператора, 24/7.

## Ценностное предложение
AI-администратор по обычному голосовому каналу: понимает запрос, работает с
реальным расписанием и доводит до результата — созданной/перенесённой записи.

## Функции (по ТЗ DBI)
1. Понять запрос → 2. Найти врача → 3. Найти слот → 4. Создать запись →
5. Сообщить статус → 6. Перенести → 7. Актуальное расписание.

## Метрики (измеримые)
- Task Success Rate по 14 сценариям eval ≥ 90%.
- Slot Precision: 100% названных слотов существуют в БД (validator gate).
- Zero double-booking: повторный COMMIT с тем же idempotency_key = 1 запись.
- Race recovery: уведённый слот → перепредложение, без падения.
- p50 turn < 1.5с (текст), voice p95 ≤ 2.5с (цель пилота).

## Ограничения
- Нет диагностики/лечения (только администрирование).
- Идентификация пациента — plug-in после ТЗ 13.10 (сейчас `PatientRef`).
- STT/TTS — заменяемые провайдеры; демо работает и на тексте.
